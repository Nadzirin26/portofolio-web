VERSI HTML PORTOFOLIO

Buka index.html langsung di browser. Tidak memerlukan PHP, Composer, internet, atau database.

Alur: Mulai Penilaian > Identitas > 5 indikator rubrik demo > Hasil > Cetak / Simpan PDF.
Data berada di memori halaman dan hilang saat reload. PDF memakai dialog cetak browser.

Versi ini dibuat terpisah dari project PHP asli. Identitas institusi, pembimbing, pengembang, narahubung, logo, dan tautan eksternal tidak disertakan.

Demo dipersingkat menjadi 5 indikator dari 5 kategori. Skor maksimum 15 dinormalisasi ke skala 100.
